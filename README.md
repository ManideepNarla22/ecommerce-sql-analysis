# E-Commerce SQL Analysis

## Project Overview

This project is a mini e-commerce database built using MySQL to practice relational database design and SQL-based business analysis.

The database contains customer, product, order, and order-item information. SQL queries are used to analyze sales, revenue, customer spending, order activity, and product performance.


## Database Schema

The project consists of four main tables:


### 1. Customers

Stores information about customers.

| Column | Description |
|---|---|
| customer_id | Unique customer ID |
| name | Customer name |
| email | Customer email |
| city | Customer city |


### 2. Products

Stores information about products.

| Column | Description |
|---|---|
| product_id | Unique product ID |
| product_name | Name of the product |
| category | Product category |
| price | Product price |


### 3. Orders

Stores information about customer orders.

| Column | Description |
|---|---|
| order_id | Unique order ID |
| customer_id | Customer who placed the order |
| order_date | Date of the order |
| status | Order status |


### 4. Order Items

Stores the products included in each order.

| Column | Description |
|---|---|
| order_item_id | Unique order-item ID |
| order_id | Associated order |
| product_id | Associated product |
| quantity | Quantity purchased |


## Table Relationships

Customers

    |

Order Items
    |

- One customer can place multiple orders.
- One order can contain multiple products.
- One product can appear in multiple orders.
- Foreign keys are used to maintain relationships between tables.


## Business Questions

1. How many orders are there in each order status?
2. What is the total revenue generated by each product?
3. What is the total revenue generated by each category?
4. How much has each customer spent?
5. How many orders has each customer placed?
6. What is the average order value?
7. Which products are the best-selling based on quantity?
8. Which customers have spent more than ₹2,000?
9. What is the most expensive product?
10. Which products have never been ordered?

## How to Run the Project

### Prerequisites

- MySQL Server
- MySQL Workbench or any MySQL-compatible SQL client

### Steps

1. Clone this repository.
2. Open schema.sql.
3. Execute the complete file to create the database and tables.
4. Open data.sql and execute it to insert the sample data.
5. Open analysis.sql.
6. Execute the queries to perform the analysis.
